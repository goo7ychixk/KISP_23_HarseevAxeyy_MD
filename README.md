# Введение в JavaScript

JavaScript изначально создавался для того, чтобы сделать веб-страницы интерактивными. Программы на нём называются **скриптами**: они встраиваются в HTML и могут выполняться при загрузке страницы.

Скрипты распространяются как обычный текст и не требуют отдельной подготовки или компиляции для запуска. Несмотря на название, JavaScript не связан с Java.

## Где работает JavaScript

JavaScript выполняется в специальных программах — **движках JavaScript**. В браузерах есть собственные движки: например, V8 используется в Chrome, Opera и Edge, а SpiderMonkey — в Firefox.

Движок читает и разбирает код, преобразует его в машинный код, а затем запускает. Во время работы он также оптимизирует код, чтобы повысить производительность.

JavaScript работает не только в браузере, но и на серверах и других устройствах. Возможности языка зависят от среды: например, Node.js предоставляет функции для работы с файлами и сетевыми запросами.

## Возможности JavaScript в браузере

С помощью JavaScript можно:

- добавлять и изменять HTML-содержимое и стили страницы;
- реагировать на действия пользователя;
- отправлять сетевые запросы и обмениваться данными с сервером;
- работать с куки и локальным хранилищем;
- запрашивать доступ к камере, микрофону и другим устройствам.

## Ограничения и безопасность

В браузере JavaScript ограничен, чтобы защитить пользователя. Веб-страница не может свободно читать и изменять файлы на устройстве или запускать программы. Доступ к файлам и устройствам требует разрешения или действия пользователя.

**Политика одинакового источника** ограничивает взаимодействие между страницами с разных источников — то есть с разными доменами, протоколами или портами. Обмен данными с другими сайтами возможен, если удалённый сервер явно разрешает его.

Вне браузера, например на сервере, браузерные ограничения не действуют. Расширения браузера также могут получать дополнительные разрешения.

## Почему JavaScript особенный

JavaScript:

- интегрирован с HTML и CSS;
- позволяет просто решать типичные задачи веб-разработки;
- поддерживается всеми основными браузерами и включён по умолчанию.

Благодаря этому он стал основным языком для создания интерактивных интерфейсов в браузере. Его также используют на серверах и мобильных устройствах.

## Языки, которые преобразуются в JavaScript

Некоторые языки и инструменты добавляют возможности или другой синтаксис, а затем преобразуют код в JavaScript. Этот процесс называется **транспиляцией**.

- **TypeScript** добавляет строгую типизацию и помогает работать с большими проектами.
- **Flow** также добавляет типизацию, но использует другой подход.
- **CoffeeScript** предлагает более краткий синтаксис.
- **Dart** может работать за пределами браузера; для запуска в браузере его код преобразуют в JavaScript.
- **Brython** позволяет писать код на Python, который преобразуется в JavaScript.

Даже используя такие инструменты, важно понимать JavaScript, чтобы разбираться в работе программы.

## Главное

JavaScript начинался как язык для браузера, но теперь используется на разных платформах. Его тесная интеграция с HTML и CSS и широкая поддержка браузерами делают его ключевым инструментом веб-разработки.

# Редакторы кода

Программисты проводят много времени в редакторах кода. Редакторы делятся на два основных типа: **IDE** и **лёгкие редакторы**. Часто используют оба типа.

## IDE

**IDE** — интегрированная среда разработки, предназначенная для работы над целым проектом. Она может:

- открывать и переключать файлы проекта;
- предлагать автодополнение по всему проекту;
- работать с Git и другими системами контроля версий;
- интегрироваться со средствами тестирования и другими инструментами.

**Примеры:**

- Visual Studio Code — бесплатная и кроссплатформенная;
- WebStorm — кроссплатформенная, бесплатна для некоммерческого использования;
- Visual Studio — мощная среда для Windows и .NET; доступна бесплатная версия Visual Studio Community.

Некоторые IDE платные, но часто предлагают пробный период.

## Лёгкие редакторы

Лёгкие редакторы обычно быстрее и проще IDE. Их удобно использовать, чтобы быстро открыть и отредактировать отдельный файл.

**Примеры:**

- Sublime Text — кроссплатформенный, условно-бесплатный;
- Notepad++ — бесплатный редактор для Windows;
- Vim и Emacs — мощные редакторы, требующие навыков работы.

Плагины могут добавлять лёгким редакторам автодополнение и анализ кода. Поэтому граница между ними и IDE не всегда чёткая.

## Как выбрать редактор

Выбор зависит от проектов, привычек и личных предпочтений. Попробуйте разные варианты и остановитесь на том, который лучше подходит для вашей работы.

## Консоль разработчика

**Инструменты разработчика (DevTools)** помогают находить и исправлять ошибки в коде. В консоли можно просматривать сообщения об ошибках, запускать JavaScript-команды и проверять значения переменных.

## Как открыть консоль

- **Chrome:** нажмите `F12`; на Mac — `Cmd + Option + J`.
- **Firefox, Edge и другие браузеры:** обычно `F12`.
- **Safari:** сначала включите меню «Разработка» в настройках: **Настройки → Дополнительно**. Затем откройте консоль сочетанием `Cmd + Option + C`.

Внешний вид инструментов может отличаться в зависимости от браузера и его версии, но основные принципы работы похожи.

## Просмотр ошибок и выполнение команд

Ошибки отображаются в консоли, обычно красным цветом. Рядом с сообщением часто указаны файл и строка кода, где произошла ошибка.

В командной строке консоли можно вводить JavaScript и запускать его клавишей `Enter`. Чтобы перейти на новую строку, не выполняя код, нажмите `Shift + Enter`.

## Главное

DevTools позволяют видеть ошибки, выполнять команды и исследовать работу кода. Освоив консоль, вы сможете быстрее находить и устранять проблемы в JavaScript.

## Привет, мир!

JavaScript-код можно запускать в браузере или в серверной среде, например Node.js. В браузере код часто размещают внутри HTML-тега `<script>`.

## Встроенный скрипт

Код внутри тега `<script>` выполняется, когда браузер обрабатывает этот тег:

```html
<script>
  alert('Привет, мир!');
</script>
```

Скрипт можно разместить в разных местах HTML-документа.

## Атрибуты тега `<script>`

- `type` обычно не нужен для обычного JavaScript-кода. В современном HTML он также используется для модулей.
- `language` устарел: JavaScript и так является языком скриптов по умолчанию.
- HTML-комментарии внутри `<script>` — устаревший способ скрывать код от старых браузеров и в современном коде не нужны.

## Внешние скрипты

Код можно вынести в отдельный файл и подключить его атрибутом `src`:

```html
<script src="script.js"></script>
```

В пути можно использовать адрес относительно текущей страницы, абсолютный путь или полный URL. Для подключения нескольких файлов используют отдельный тег `<script>` для каждого.

Внешние файлы удобны для организации кода и могут кэшироваться браузером, чтобы не загружать их повторно при переходе на другие страницы.

Если указан `src`, содержимое внутри того же тега `<script>` игнорируется. Поэтому внешний файл и встроенный код нужно подключать отдельными тегами.

## Главное

Для добавления JavaScript на страницу используйте `<script>`. Атрибуты `type` и `language` для обычных скриптов не требуются, а большие скрипты удобно хранить в отдельных файлах.

## Структура кода

Код JavaScript состоит из **инструкций** — команд, которые выполняют действия. Например, `alert('Привет');` показывает сообщение.

## Инструкции и точки с запятой

Инструкции можно разделять точками с запятой и обычно записывать каждую с новой строки:

```js
alert('Привет');
alert('Мир');
```

JavaScript часто автоматически вставляет точку с запятой при переходе на новую строку. Однако это происходит не всегда: например, строка, начинающаяся с `[` или `(`, может продолжить предыдущую инструкцию. Поэтому безопаснее явно ставить точку с запятой между инструкциями.

## Комментарии

Комментарии поясняют код и игнорируются при выполнении.

Однострочный комментарий начинается с `//`:

```js
// Показываем приветствие
alert('Привет'); // Комментарий после инструкции
```

Многострочный комментарий заключают между `/*` и `*/`:

```js
/*
  Это многострочный
  комментарий
*/
alert('Мир');
```

Комментарии также можно использовать, чтобы временно отключить участок кода. Вложенные комментарии вида `/* ... /* ... */ ... */` не поддерживаются.

## Главное

- Размещайте инструкции на отдельных строках и разделяйте их точками с запятой.
- Используйте `//` для однострочных комментариев и `/* ... */` для многострочных.
- Комментарии не влияют на выполнение программы.

## Строгий режим — `"use strict"`

В JavaScript строгий режим включает более современное и строгое поведение языка. Он появился в ECMAScript 5, чтобы исправить некоторые особенности старого JavaScript, не нарушая работу существующего кода.

## Как включить строгий режим

Поместите директиву `"use strict"` или `'use strict'` в начало скрипта:

```js
"use strict";

// Код выполняется в строгом режиме
```

Она должна находиться до любых исполняемых инструкций. Перед ней допустимы только комментарии. Если поставить директиву позже, строгий режим не включится.

Строгий режим также можно включить в начале функции, но он действует только внутри неё. Выключить его после включения нельзя.

## Строгий режим в консоли

В консоли браузера строгий режим может быть выключен по умолчанию. Для многострочного ввода используйте `Shift + Enter` и начните код с директивы:

```js
'use strict';
// Ваш код
```

## Когда нужен `"use strict"`

Для обычных скриптов полезно добавлять директиву в начало файла. В JavaScript-модулях и классах строгий режим включён автоматически, поэтому там она не требуется.

## Главное

- `"use strict"` включает строгий режим для скрипта, если стоит в его начале.
- В классах и модулях строгий режим действует автоматически.
- Строгий режим нельзя отключить после включения.

# Конспект: переменные в JavaScript

### Что такое переменная

Переменная — это именованное место для хранения данных. Она помогает программе сохранять и использовать информацию: например, имя пользователя, товары в корзине, сообщения чата или результаты вычислений.

Чтобы создать переменную, используют ключевое слово `let`:

```js
let message;
```

После объявления в переменную можно записать значение с помощью оператора присваивания `=`:

```js
message = 'Hello!';
```

Объявление и присваивание можно объединить:

```js
let message = 'Hello!';
```

Значение переменной можно прочитать, обратившись к ней по имени:

```js
alert(message); // Hello!
```

Если присвоить переменной новое значение, прежнее будет заменено:

```js
let message = 'Hello!';
message = 'World!';

alert(message); // World!
```

Можно скопировать значение одной переменной в другую. После этого обе переменные содержат одинаковые данные, но остаются независимыми:

```js
let hello = 'Hello world!';
let message = hello;

alert(hello);   // Hello world!
alert(message); // Hello world!
```

### Объявление нескольких переменных

Несколько переменных можно объявить в одной строке:

```js
let user = 'John', age = 25, message = 'Hello';
```

Однако обычно удобнее объявлять каждую переменную на отдельной строке. Так код легче читать и изменять:

```js
let user = 'John';
let age = 25;
let message = 'Hello';
```

### `let`, `const` и `var`

В JavaScript есть три ключевых слова для объявления переменных:

- `let` — современный способ объявить переменную, значение которой может меняться.
- `const` — объявляет переменную, которую нельзя переназначить.
- `var` — старый способ объявления переменных. В современном коде обычно предпочитают `let` и `const`.

Пример использования `let`:

```js
let age = 25;
age = 26; // можно изменить значение
```

Пример использования `const`:

```js
const myBirthday = '18.04.1982';
// myBirthday = '01.01.2001'; // ошибка: нельзя переназначить
```

Повторно объявить переменную с тем же именем через `let` или `const` в одной области видимости нельзя:

```js
let message = 'Это';
let message = 'Другое'; // SyntaxError
```

Объявите переменную один раз, а затем используйте её без повторного `let`.

### Константы и стиль их именования

Ключевое слово `const` не позволяет присвоить переменной новое значение. Но если переменная содержит объект или массив, сам объект или массив всё ещё может быть изменён — `const` запрещает именно переназначение переменной.

Для заранее известных значений, которые служат понятными именами для трудно запоминаемых данных, часто используют заглавные буквы и подчёркивания:

```js
const COLOR_RED = '#F00';
const COLOR_GREEN = '#0F0';
const COLOR_BLUE = '#00F';
```

Такой стиль удобен для значений, которые известны до запуска программы и не меняются. А для значений, которые вычисляются во время выполнения, обычно используют обычную верблюжью нотацию:

```js
const pageLoadTime = 1200;
```

### Имена переменных

Имя переменной может включать буквы, цифры, символы `$` и `_`. При этом оно не должно начинаться с цифры.

Допустимые имена:

```js
let userName;
let test123;
let $price;
let _value;
```

Недопустимые имена:

```js
// let 1a;       // имя не может начинаться с цифры
// let my-name;  // дефис не разрешён
```

Регистр имеет значение: `apple` и `APPLE` — разные переменные.

Если имя состоит из нескольких слов, обычно используют верблюжью нотацию: первое слово пишут со строчной буквы, а каждое следующее — с заглавной:

```js
let myVeryLongName;
let shoppingCart;
let currentUser;
```

JavaScript допускает имена на разных языках, включая кириллицу. Но в командах обычно выбирают английские названия, чтобы код было проще читать разработчикам из разных стран.

Нельзя использовать зарезервированные слова JavaScript в качестве имён переменных. Например, `let`, `class`, `return` и `function` уже имеют специальное назначение в языке.

### Строгий режим

Переменную нужно объявить до того, как в неё записывают значение. В строгом режиме попытка создать переменную простым присваиванием вызовет ошибку:

```js
'use strict';

num = 5; // ошибка: переменная не объявлена
```

Правильный вариант:

```js
'use strict';

let num = 5;
```

Так проще заметить ошибки и избежать случайного создания переменных.

### Как выбирать хорошие имена

Название переменной должно ясно показывать, какие данные она хранит. Например, `currentUser` информативнее, чем `data`, а `shoppingCart` — понятнее, чем `x`.

Полезные правила:

- выбирайте легко читаемые и описательные имена;
- избегайте непонятных сокращений и однобуквенных названий, если только они не очевидны из контекста;
- не делайте названия слишком общими: `value` и `data` часто не объясняют, что именно хранится;
- используйте одинаковые термины для одинаковых сущностей во всём проекте.

Хорошие имена помогают быстрее понять код, особенно если к нему приходится возвращаться спустя время или его читают другие разработчики.

### Не переиспользуйте переменные без необходимости

Не стоит использовать одну переменную для разных, не связанных между собой значений только ради экономии строк кода. Например, если переменная сначала хранит имя пользователя, а позже — стоимость заказа, читать и отлаживать такой код сложнее.

Лучше создавать отдельную переменную для каждого понятного назначения. Это делает код яснее и облегчает поиск ошибок.

### Главное

- `let` используют для переменных, значение которых может меняться.
- `const` используют, когда переменную не нужно переназначать.
- `var` — устаревший способ объявления.
- Переменную нельзя повторно объявить через `let` или `const` в той же области видимости.
- Имя переменной должно быть понятным, соответствовать правилам JavaScript и отражать содержимое переменной.

## Конспект: типы данных в JavaScript

Каждое значение в JavaScript относится к определённому **типу данных**. Всего есть восемь основных типов: семь примитивных и один объектный.

JavaScript — **динамически типизированный** язык. Это означает, что переменная не закреплена за одним типом: в неё можно записать сначала строку, а затем число.

```js
let message = 'Привет';
message = 123;
```

### Числа: `number`

Тип `number` включает целые числа и числа с дробной частью:

```js
let count = 123;
let price = 12.345;
```

Для чисел доступны арифметические операции: сложение `+`, вычитание `-`, умножение `*`, деление `/` и другие.

К типу `number` также относятся особые значения:

- `Infinity` и `-Infinity` — положительная и отрицательная бесконечность. Например, деление положительного числа на ноль даёт `Infinity`.
- `NaN` — результат некорректного или неопределённого математического действия, например попытки поделить строку на число.

```js
1 / 0;          // Infinity
'не число' / 2; // NaN
```

Если в вычислении участвует `NaN`, результат обычно тоже будет `NaN`. При этом математические ошибки такого рода сами по себе не останавливают программу.

Целые числа типа `number` безопасны в диапазоне от `-(2^53 - 1)` до `2^53 - 1`. За его пределами JavaScript может терять точность: разные большие целые числа могут представляться одинаково.

### Большие целые числа: `bigint`

Тип `bigint` предназначен для целых чисел, выходящих за безопасный диапазон `number`. Чтобы создать такое значение, добавляют `n` в конце числа:

```js
const bigNumber = 123456789012345678901234567890n;
```

`bigint` используют, когда важно точно работать с очень большими целыми числами. В обычных задачах чаще достаточно типа `number`.

### Строки: `string`

Строка содержит текст и может быть заключена в одинарные, двойные или обратные кавычки:

```js
let first = 'Привет';
let second = "Здравствуйте";
```

Одинарные и двойные кавычки работают одинаково. **Обратные кавычки** позволяют вставлять в текст переменные и выражения с помощью `${...}`:

```js
let name = 'Иван';

let greeting = `Привет, ${name}!`;
let result = `Результат: ${1 + 2}`;
```

В JavaScript нет отдельного типа для одного символа. Один символ и длинный текст — всё равно значения типа `string`.

### Логические значения: `boolean`

Тип `boolean` имеет только два значения: `true` и `false`. Он часто используется для хранения ответа «да/нет» или результата проверки:

```js
let isReady = true;
let isAdult = 20 >= 18; // true
```

### Отсутствующие значения: `null` и `undefined`

`null` — специальное значение, обычно обозначающее, что данных нет или они пока неизвестны:

```js
let age = null;
```

`undefined` означает, что значение не было присвоено. Например, объявленная переменная без начального значения содержит `undefined`:

```js
let userName;

console.log(userName); // undefined
```

Обычно `null` присваивают намеренно, чтобы показать отсутствие значения, а `undefined` указывает, что значение не было задано.

### Объекты: `object`

Объекты позволяют хранить наборы данных и более сложные структуры. К объектам также относятся, например, массивы и другие составные значения. В отличие от примитивов, объекты могут содержать несколько связанных свойств.

```js
let user = {
  name: 'Иван',
  age: 25
};
```

Объекты — отдельная большая тема, которую обычно изучают подробнее после знакомства с примитивными типами.

### Уникальные идентификаторы: `symbol`

Тип `symbol` используют для создания уникальных идентификаторов, например в свойствах объектов. На начальном этапе достаточно знать, что такой тип существует.

```js
let id = Symbol('id');
```

### Оператор `typeof`

Оператор `typeof` возвращает строку с названием типа значения:

```js
typeof 5;        // "number"
typeof 10n;      // "bigint"
typeof true;     // "boolean"
typeof 'текст';  // "string"
typeof undefined; // "undefined"
```

Его можно записывать как `typeof значение` или `typeof(значение)`. Скобки полезны, когда нужно определить тип результата выражения:

```js
typeof (50 + ' квартир'); // "string"
```

Есть несколько особенностей:

- `typeof null` возвращает `"object"`. Это историческая ошибка JavaScript: `null` не является объектом.
- `typeof` для функции возвращает `"function"`, хотя отдельного примитивного типа «функция» в JavaScript нет.

### Главное

- В JavaScript восемь основных типов: `number`, `bigint`, `string`, `boolean`, `null`, `undefined`, `symbol` и `object`.
- Первые семь типов считаются примитивными; `object` предназначен для сложных структур данных.
- Переменная может хранить значения разных типов в разные моменты времени.
- `typeof` помогает определить тип, но для `null` возвращает исторически необычный результат — `"object"`.

## Конспект: взаимодействие с пользователем — `alert`, `prompt`, `confirm`

В браузере есть три простых способа показать пользователю сообщение или запросить ответ: `alert`, `prompt` и `confirm`. Все они открывают **модальные окна**: пока окно не закрыто, пользователь не может взаимодействовать с остальной частью страницы, а выполнение скрипта приостанавливается.

### `alert`

`alert` показывает сообщение и ждёт, пока пользователь нажмёт «ОК»:

```js
alert('Привет!');
```

Эта функция нужна, чтобы вывести информацию. Она не запрашивает ввод и не возвращает ответ пользователя.

### `prompt`

`prompt` показывает сообщение и поле для ввода текста:

```js
let name = prompt('Как тебя зовут?', '');
```

У функции два аргумента:

```js
prompt(title, default);
```

- `title` — текст вопроса или сообщения;
- `default` — необязательное начальное значение в поле ввода.

Если пользователь нажмёт «ОК», `prompt` вернёт введённый текст. Если нажмёт «Отмена» или клавишу Esc, функция вернёт `null`.

```js
let age = prompt('Сколько тебе лет?', '18');

if (age !== null) {
  alert(`Тебе ${age} лет!`);
}
```

Результат `prompt` обычно является строкой, даже если пользователь ввёл число. Если нужно выполнять с ним математические действия, преобразуйте значение в число, например с помощью `Number()`:

```js
let age = prompt('Сколько тебе лет?', '18');

if (age !== null) {
  let ageNumber = Number(age);
  alert(`Через год тебе будет ${ageNumber + 1}`);
}
```

### `confirm`

`confirm` показывает вопрос и две кнопки — «ОК» и «Отмена»:

```js
let isBoss = confirm('Ты здесь главный?');
```

Функция возвращает логическое значение:

- `true`, если пользователь нажал «ОК»;
- `false`, если нажал «Отмена» или Esc.

```js
if (confirm('Продолжить?')) {
  alert('Продолжаем!');
} else {
  alert('Действие отменено.');
}
```

### Краткое сравнение

| Функция | Для чего нужна | Что возвращает |
|---|---|---|
| `alert(message)` | Показать сообщение | Не возвращает ответ пользователя |
| `prompt(title, default)` | Запросить текст | Введённую строку или `null` |
| `confirm(question)` | Задать вопрос с выбором | `true` или `false` |

Внешний вид и расположение этих окон определяет браузер: изменить их оформление средствами самих функций нельзя. Для более гибкого и красивого интерфейса обычно создают собственные элементы страницы.

# Конспект: особенности JavaScript

### Структура кода

Инструкции обычно разделяются точками с запятой. JavaScript может вставлять их автоматически при переносе строки, но это срабатывает не всегда, поэтому точку с запятой рекомендуется ставить явно. После блоков кода и конструкций вроде функций или циклов она обычно не нужна.

### Строгий режим

`'use strict';` включает строгий режим. Его указывают в начале скрипта или функции, чтобы использовать современные правила JavaScript и избегать некоторых устаревших особенностей.

### Переменные и типы данных

Переменные объявляют с помощью `let`, `const` или `var`. Для нового кода обычно используют `let` и `const`; `var` — устаревший способ.

JavaScript — язык с динамической типизацией: переменной можно присваивать значения разных типов.

В языке есть восемь типов данных: `number`, `bigint`, `string`, `boolean`, `null`, `undefined`, `object` и `symbol`. У `typeof` есть особенность: `typeof null` возвращает `"object"`. Для функций он возвращает `"function"`.

### Взаимодействие с пользователем

В браузере доступны простые функции с модальными окнами:

- `alert(message)` показывает сообщение.
- `prompt(question, default)` запрашивает ввод и возвращает строку или `null`.
- `confirm(question)` предлагает подтвердить или отменить действие и возвращает `true` или `false`.

Пока окно открыто, выполнение кода и взаимодействие со страницей приостанавливаются.

### Операторы

- Арифметические: `+`, `-`, `*`, `/`, `%`, `**`.
- Присваивания: `=`, `+=`, `*=`.
- Условный: `условие ? значение1 : значение2`.
- Логические: `&&`, `||`, `!`. Операторы `&&` и `||` используют короткое замыкание и могут возвращать не только `true` или `false`.
- Нулевого слияния: `a ?? b` возвращает `b`, если `a` равен `null` или `undefined`.
- Сравнения: `==` допускает преобразование типов, а `===` сравнивает без него. Обычно предпочтительнее `===`.

Оператор `+` складывает числа, но если один из операндов — строка, то преобразует другой операнд в строку и объединяет значения.

### Циклы

Основные циклы: `while`, `do...while` и `for`. Переменная, объявленная через `let` внутри заголовка цикла `for`, видна только в пределах цикла. `break` завершает цикл, а `continue` переходит к следующей итерации.

### Конструкция `switch`

`switch` проверяет значение на совпадение с вариантами `case`, используя строгое равенство `===`. Поэтому типы тоже должны совпадать. Например, строка `"18"` не равна числу `18`. Для завершения ветки обычно используют `break`.

### Функции

Функции можно создавать тремя способами:

- **Function Declaration** — отдельное объявление `function sum() {}`.
- **Function Expression** — функция, присвоенная переменной: `let sum = function() {};`.
- **Стрелочная функция** — краткая запись: `let sum = (a, b) => a + b;`.

У функций могут быть локальные переменные и параметры со значениями по умолчанию. Функция без `return` возвращает `undefined`.


# Стрелочные функции

Стрелочная функция — краткая форма Function Expression:

```js
let func = (arg1, arg2) => expression;
```

Она принимает аргументы, вычисляет выражение и автоматически возвращает результат. Это примерно то же самое, что:

```js
let func = function(arg1, arg2) {
  return expression;
};
```

### Аргументы

- **Несколько аргументов:** параметры указывают в круглых скобках.
  ```js
  let sum = (a, b) => a + b;
  ```
- **Один аргумент:** круглые скобки можно опустить.
  ```js
  let double = n => n * 2;
  ```
- **Нет аргументов:** нужны пустые круглые скобки.
  ```js
  let sayHi = () => alert("Привет!");
  ```

Стрелочную функцию можно, например, присвоить переменной или использовать для условного выбора функции:

```js
let welcome = age < 18
  ? () => alert("Привет!")
  : () => alert("Здравствуйте!");

welcome();
```

### Многострочные функции

Если тело функции заключено в фигурные скобки, оно может содержать несколько инструкций. Чтобы вернуть значение, нужно явно написать `return`:

```js
let sum = (a, b) => {
  let result = a + b;
  return result;
};
```

### Главное

- `(...args) => expression` автоматически возвращает результат выражения.
- `n => expression` — сокращённая запись для функции с одним аргументом.
- `() => expression` используется, если аргументов нет.
- В теле с фигурными скобками для возврата значения требуется `return`.
- Стрелочные функции особенно удобны для коротких действий и колбэков.

# Function Expression и Function Declaration

### Функция — это значение

В JavaScript функцию можно сохранить в переменной, скопировать, передать как аргумент и вызвать позже.

```js
function sayHi() {
  alert("Привет");
}

let func = sayHi;
func(); // Привет
```

`func = sayHi` копирует функцию. Если написать `sayHi()`, в переменную попадёт результат вызова, а не сама функция.

### Function Declaration

Функция объявляется отдельной инструкцией:

```js
function sum(a, b) {
  return a + b;
}
```

- Объявление обрабатывается до выполнения кода в блоке.
- Функцию можно вызвать до её объявления.
- В строгом режиме функция, объявленная внутри блока `{}`, доступна только внутри этого блока.

### Function Expression

Функция создаётся в составе выражения, например при присваивании:

```js
let sum = function(a, b) {
  return a + b;
};
```

- Функция создаётся, когда выполнение доходит до выражения.
- До этого момента вызвать её нельзя.
- Имя можно не указывать: такая функция называется анонимной.
- Точка с запятой ставится в конце выражения присваивания, а не после тела функции как отдельное правило.

### Колбэки

Колбэк — это функция, переданная другой функции как аргумент и вызываемая при необходимости.

```js
function ask(question, yes, no) {
  if (confirm(question)) yes();
  else no();
}

ask(
  "Вы согласны?",
  function() { alert("Вы согласились."); },
  function() { alert("Вы отказались."); }
);
```

### Когда что использовать

Обычно удобнее использовать **Function Declaration**: её можно вызвать до места объявления, и она заметнее в коде.

**Function Expression** подходит, когда функцию нужно присвоить переменной, передать как колбэк или создать условно.

### Главное

- Функции — это значения: их можно присваивать, копировать и передавать.
- Function Declaration доступна в блоке до строки объявления.
- Function Expression доступна после того, как выполнение дошло до неё.
- Объявления функций внутри блока в строгом режиме снаружи блока недоступны.



# Функции в JavaScript

Функция — это блок кода, который выполняет определённое действие. Она помогает не дублировать код и делает программу понятнее.

### Объявление и вызов

Функцию объявляют с помощью `function`, затем указывают её имя, параметры и тело:

```js
function showMessage() {
  alert('Всем привет!');
}

showMessage();
```

Вызов функции по имени запускает её код. Одну функцию можно вызывать несколько раз.

### Переменные и область видимости

Переменные, созданные внутри функции, — **локальные**. Они доступны только внутри неё:

```js
function showMessage() {
  let message = 'Привет!';
  alert(message);
}
```

Функция может обращаться к переменным снаружи — **внешним переменным**. Если внутри функции объявлена переменная с таким же именем, она перекрывает внешнюю. Переменные, объявленные вне всех функций, называют **глобальными**. Их использование лучше сводить к минимуму.

### Параметры и аргументы

**Параметры** указывают в объявлении функции, а **аргументы** передают при её вызове:

```js
function showMessage(from, text) {
  alert(from + ': ' + text);
}

showMessage('Аня', 'Привет!');
```

Переданные значения копируются в параметры: изменение параметра внутри функции не меняет исходную переменную снаружи.

### Значения по умолчанию

Если аргумент не передан, параметр получает значение `undefined`. Чтобы задать значение по умолчанию, используйте `=`:

```js
function showMessage(from, text = 'текст не добавлен') {
  alert(from + ': ' + text);
}
```

Значение по умолчанию вычисляется при вызове функции, если соответствующий аргумент не передан. Для значений, где `0` или пустая строка могут быть допустимыми, удобно использовать оператор `??`:

```js
function showCount(count) {
  alert(count ?? 'неизвестно');
}
```

### Возврат результата

`return` завершает выполнение функции и возвращает результат:

```js
function sum(a, b) {
  return a + b;
}

let result = sum(1, 2); // 3
```

Если функция завершается без `return` или использует пустой `return`, она возвращает `undefined`. Не ставьте перевод строки сразу после `return`: JavaScript может воспринять его как пустой возврат.

### Имена и устройство функций

Имя функции обычно описывает действие и начинается с глагола:

- `show…` — показывает;
- `get…` — получает или возвращает значение;
- `calc…` — вычисляет;
- `create…` — создаёт;
- `check…` — проверяет и обычно возвращает `true` или `false`.

Хорошая функция выполняет одно действие, соответствующее её названию. Короткие функции легче читать, проверять и отлаживать. Вспомогательные функции с ясными именами могут пояснять логику кода лучше комментариев.


# Конструкция `switch`

`switch` — наглядный способ сравнить одно выражение с несколькими значениями. Он проверяет их на **строгое равенство** (`===`).

### Синтаксис

```js
switch (выражение) {
  case значение1:
    // код
    break;

  case значение2:
    // код
    break;

  default:
    // код, если совпадений нет
}
```

- `case` задаёт вариант для сравнения.
- `break` завершает выполнение `switch`.
- `default` — необязательный блок, который выполняется, если ни один `case` не подошёл.

### Как работает `break`

После совпадения `switch` выполняет код соответствующего `case`. Если нет `break`, выполнение продолжается в следующих блоках, даже не проверяя их условия. Это называется «проваливанием» (`fall-through`).

```js
switch (a) {
  case 3:
    alert('Маловато');
    break;
  case 4:
    alert('В точку!');
    break;
  default:
    alert('Нет таких значений');
}
```

Обычно после каждого `case` ставят `break`, чтобы случайно не выполнить следующий блок.

### Группировка вариантов

Несколько `case` можно объединить, если для них нужен один и тот же код:

```js
switch (a) {
  case 3:
  case 5:
    alert('Неправильно!');
    break;
  case 4:
    alert('Правильно!');
    break;
}
```

Здесь для значений `3` и `5` выполнится общий код.

### Выражения и типы

В `switch` и `case` можно использовать выражения:

```js
let a = '1';
let b = 0;

switch (+a) {
  case b + 1:
    alert('Совпадение');
    break;
}
```

Поскольку `+a` превращается в число `1`, оно совпадает с результатом `b + 1`.

Сравнение строгое, поэтому строка `'3'` не равна числу `3`. Например, `prompt()` возвращает строку, поэтому `case 3` не совпадёт с введённым значением `"3"`. Чтобы совпадение сработало, преобразуйте значение в число или используйте строковый вариант `case '3'`.



# Циклы в JavaScript

Циклы позволяют многократно выполнять один и тот же участок кода. Одно повторение тела цикла называется **итерацией**.

### `while`

Проверяет условие **перед каждой итерацией**. Пока условие истинно, цикл продолжается:

```js
let i = 0;

while (i < 3) {
  console.log(i);
  i++;
}
```

Если условие сразу ложно, тело цикла не выполнится ни разу. Следите, чтобы условие могло стать ложным, иначе цикл будет бесконечным.

### `do...while`

Сначала выполняет тело, а затем проверяет условие. Поэтому тело выполнится **как минимум один раз**:

```js
let i = 0;

do {
  console.log(i);
  i++;
} while (i < 3);
```

### `for`

Удобен, когда заранее известны счётчик и условие продолжения:

```js
for (let i = 0; i < 3; i++) {
  console.log(i);
}
```

В заголовке цикла:

- `let i = 0` — начало, выполняется один раз;
- `i < 3` — условие, проверяется перед каждой итерацией;
- тело — действия, повторяемые циклом;
- `i++` — шаг, выполняется после каждой итерации.

Любую из частей `for` можно пропустить, но точки с запятой между частями нужно оставить. `for (;;)` создаёт бесконечный цикл.

### `break` и `continue`

`break` полностью завершает цикл:

```js
while (true) {
  let value = prompt('Введите число');

  if (!value) break;
}
```

`continue` прекращает текущую итерацию и переходит к следующей:

```js
for (let i = 0; i < 10; i++) {
  if (i % 2 === 0) continue;
  console.log(i); // нечётные числа
}
```

`break` и `continue` нельзя использовать в тернарном выражении.

### Метки для вложенных циклов

Метка позволяет выйти из нескольких вложенных циклов или перейти к следующей итерации внешнего цикла:

```js
outer: for (let i = 0; i < 3; i++) {
  for (let j = 0; j < 3; j++) {
    if (i === j) break outer;
  }
}
```

Метка указывается перед циклом, а `break outer` завершает цикл с этой меткой. `continue` с меткой переходит к следующей итерации соответствующего цикла.

### Кратко

- `while` — проверяет условие перед выполнением тела.
- `do...while` — выполняет тело хотя бы один раз, затем проверяет условие.
- `for` — объединяет начало, условие и шаг в заголовке.
- `break` — завершает цикл.
- `continue` — пропускает остаток текущей итерации.
- Метки помогают управлять вложенными циклами.
